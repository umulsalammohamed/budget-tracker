# Budget Tracker - Visual Identity (Week 3 CSS Challenge)
Improved my existing Budget Tracker focusing only on CSS.

Files: index.html (header, form, table), style.css (visual design), README.md

1. Color Palette: Primary #1a5d4f Deep Teal for headings/table/buttons, BG #f5f7f6, Secondary #e8f5e9 for hover, White cards, Text #2d3748, Border #e2e8f0. Applied consistently.

2. Typography: Google Fonts Poppins 600,700 for headings, Inter 400,500,600 for body. Hierarchy h1 2.2rem, h2 1.4rem.

3. Table/Form: Table padding 14px, teal header white text, borders, alternating rows, hover mint, rounded wrapper. Form padding 12px, border focus glow, 8px radius, cohesive button.

4. Box Model: Margin 24px between cards, 18px between groups, Padding 28px inside cards, Borders 1px + 5px left accent, Border-radius 12px cards 8px inputs. Three distinct cards: header-card, form-card, table-card with shadow.
